# Pokémon Journey

**Pokémon Journey** é um fangame em desenvolvimento com foco em exploração, vida no mundo Pokémon e uma experiência mais viva entre treinador, Pokémon e NPCs.

## Journey 0.1

Esta primeira etapa cria a fundação técnica do projeto.

### Já incluído

- C++20
- SDL3
- CMake
- janela principal do jogo
- game loop
- movimentação básica
- estrutura inicial separando jogo e engine

## Plataformas planejadas

O projeto está sendo estruturado para futuramente funcionar em:

- Windows
- Linux
- Android
- iOS

## Direção do projeto

O Journey será um jogo 2D/2.5D com visual próprio, inspirado na fluidez e riqueza dos jogos modernos de pixel art.

A ideia é criar um mundo Pokémon com:

- Pokémon visíveis no mapa
- Pokémon seguidores
- batalhas animadas
- captura
- evolução
- exploração
- cidades e rotas detalhadas
- clima
- ciclo de dia e noite
- NPCs com rotina
- relacionamentos
- casas
- empregos
- economia
- Living Trainers
- múltiplas regiões
